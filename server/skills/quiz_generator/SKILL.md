# 出题技能（Quiz Generator）

## 目标
产出一份可直接作答、附参考答案与解析的练习题。

## 执行步骤
1. **理解输入**：从用户请求中提取
   - 主题/知识点（必须，如"一元二次方程"）
   - 题目数量 count（缺省 5，1–20 道）
   - 难度 difficulty（easy/medium/hard，**缺省 medium，不必澄清**）
   - **当用户已给出主题与数量（如"出 5 道一元二次方程"）时，禁止任何澄清，直接按默认难度 medium 出题**；仅当主题或数量缺失时才需澄清：在回复首行输出
     `ASK_QUESTION：你想练习哪个知识点？大概几道题？`，可另附选项行
     `ASK_OPTION：一元二次方程` `ASK_OPTION：函数`，然后结束本轮等待学生回答。
2. **设计题目**：题型可混合——选择题（给出 A/B/C/D）、填空题、简答题。
   难度对应：
   - easy：直接套公式/概念辨析
   - medium：需要两步变形
   - hard：综合运用/含参数讨论
3. **逐题输出**，每题结构：
   - 题干（数学公式用 LaTeX：`$...$`）
   - 选择题给选项；其余题型留作答区
   - **参考答案**与**简要解析**（用引用块 `>` 或折叠块，便于学生自查）
4. **收尾**：提示学生可把答案发回，申请批改。

## 输出格式要求
- Markdown，标题含主题与题量（如 `## 一元二次方程 · 练习（5 题，难度 medium）`）
- 题号从 1 连续编号
- 全部简体中文
- **不要用完成语/横幅收尾**（如"出好了 ✅""以上就是…"），题目结束直接自然收尾或提示可把答案发回批改
- **emoji 最多 1 个**，题干与解析中不用 emoji 装饰

## 边界
- 只出题与解析，不代替学生作答
- 题面必须自洽、答案准确；不确定的知识点宁可不选
- 用户要求批改 → 提示该功能（调用 answer_grader 或告知）。
